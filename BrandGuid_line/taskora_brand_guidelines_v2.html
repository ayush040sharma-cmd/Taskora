01 — Logo
The Mark
The Taskora mark fuses the letterform "T" with a forward-pointing arrow into a single unified silhouette — one shape, one gradient sweep — representing execution (motion, direction) and the product name at once. It is built as one closed path, not layered or overlapping forms, so it reads cleanly at any size.
Construction
The crossbar of the T tapers directly into the arrow tip — no separate shapes bolted together, no ambiguity about foreground/background. The gradient runs consistently from top-left (#3B82F6) to bottom-right (#06B6D4) across the full bounding box.

03 — Spacing & Scale
Clear Space & Minimum Size
Clear space
Minimum clear space on all sides equals the width of the mark's vertical stem (the "T" leg). Never place other UI elements, text, or edges inside this zone.
Minimum size
24px digital min
16px favicon
Below 24px, use the icon-only mark. Below 16px is not recommended — use the simplified favicon variant (Section 08) instead.
04 — Color Variants
On Different Backgrounds
On navy (default)
On white / light
Single-color (embroidery, stamps, fax)
The gradient mark works on both navy and light-neutral backgrounds. Never place it on a busy photographic background, a mid-tone color that fights the gradient, or a brand-color background (blue-on-blue loses contrast).
05 — Correct Usage
Do & Don't
Do
Use the provided SVG source file at any scale — it's vector, it never degrades.

Maintain the exact gradient angle and stop colors (#3B82F6 → #06B6D4).

Keep the icon and wordmark in their locked proportions when using the primary lockup.
Don't
Stretch, skew, or rotate the mark.

Recolor it outside the approved gradient or single-color variant.

Add drop shadows, glows, or outlines not specified here.

Set the wordmark in a font other than Syne, or in Title Case.
